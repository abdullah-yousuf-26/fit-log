# 💪 FitLog 


&gt; A dark, no-nonsense gym companion: pick a lift, lock it into today's plan, and watch the week's work add up.

FitLog is a workout tracking web app where you can browse a library of 12 exercises, view detailed instructions & specs, build your daily plan, and save workouts for later — all wrapped in a bold, dark UI with a lime accent.

---


## Technologies Used

| Technology | Purpose |
|---|---|
| **Next.js (App Router)** | UI framework & routing |
| **TypeScript** | Type-safe code |
| **Tailwind CSS** | Styling & responsiveness |
| **React Icons** | Icons (stats, buttons, badges) |
| **React Hot Toast** | Toast notifications |
| **localStorage** | Persisting plan & saved data |

---

## 5 Key Features

1. **Workout Library** 
Browse 12 exercises from a live API in a responsive card grid, each showing muscle-group tags, equipment, duration, calories & rating.

2. **Detailed Workout Pages** 
Every workout has its own page with a full spec panel (equipment, difficulty, sets, reps, duration, calories, rating) and step-by-step instructions.

3. **Today's Plan & Saved Lists** 
 Add workouts to your daily plan or save them for later — with live navbar counters showing how many you've collected.

4. **Live Metrics Dashboard** 
The My Plan page tracks Exercises, total Minutes, and total Calories, updating in real time as you add or remove lifts.

5. **Smart Extras** 
 Tab-based plan/saved views, sort by Duration/Calories/Rating, toast notifications, persistent data via localStorage, and a fully responsive dark UI with a lime accent.
